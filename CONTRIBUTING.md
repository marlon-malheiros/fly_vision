# Contributing

Run `python -m pytest` and the full replay described in the README. Keep output in
a new `generated/` directory. Preserve the reference evidence and failed runs;
document corrections in new versions, with a dated progress entry and validation.

Changes to scientific rules must be distinguished from the frozen pilot and from
the post-outcome R2 correction. Report wrong-family retention and unresolved
outcomes alongside generating-family rejection. Avoid biological or novelty
claims beyond the data.

Please discuss substantial research changes in an issue before changing scope.
