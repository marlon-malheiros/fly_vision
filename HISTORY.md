history through 2026-11-16. The initial README describes the earlier, pilot-only
release; this archive was added afterwards. It does not add the full parent
workspace, all raw recordings, or the complete Git object history.

Historical reports include failed tests, decisions, numerical corrections and
exploratory findings. Read each result with its own protocol and limitations.
Numerical checks are not biological validation, and later corrections do not
retroactively become prospectively frozen rules.
