# Publishing this prepared repository

This directory is the prepared repository root. It contains no `.git` directory
and no configured remote. Publish from a separate copy of this directory, not
from the parent research workspace with its broader history and local archives.

Before publication, review the README, license scopes, manuscript authorship
placeholders and the validation snapshot. No publication or remote upload is
performed by the reproduction commands.

If making a repository on GitHub, use the prepared files for its initial commit.
The supplied workflow runs the tests, inventory check and numerical replay on
push and pull requests. It has read-only repository permissions and does not
publish releases or documents.
