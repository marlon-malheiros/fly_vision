# Study B — evidence-constrained anatomical strengthening V1

Prepared 2026-10-19. This is a separate study. Every executable reconstruction,
freeze and simulation action requires the completed immutable Study A seal. No
Study A parameter, observation, acceptance criterion or artifact will be changed.
Code preparation/source inventory can occur while Study A computes; expanded
circuits and comparative experiments cannot run before that completion.

## Anatomical inclusion rules

Use the original MaleCNS v1.0 official body annotations, neurotransmitter table
and complete min-confidence-0.5 chemical weight table, not an invented motif.
Audit all original model identities and type-level signs. Candidate uLPTCrn-family
homologs are the published/ontology-linked hemibrain PS070–PS074 classes present
in MaleCNS; H2rn homologs are ontology-linked FlyWire CB3740 and CB3748 classes.
Preserve cross-dataset homology qualifications, subtype multiplicity, anatomical
side and source confidence. Require annotation identity, same-body neurotransmitter
consensus GABA, confidence ≥0.5, and existing connections to the selected network.
Never choose candidates by yaw response or improve a classifier by pruning cells.
Record rejected/ambiguous candidates rather than manufacturing a missing pair.

Stream all original chemical edge rows and retain only verified selected body
pairs. Save integer counts and the full new-edge ledger. Build the expanded
chemical circuit with the existing signed-linear count conversion, class gains
of one and postsynaptic absolute-sum normalization. Reconstruct the original
body subset from the same raw table and quantify differences from the frozen
matrix. Report effects of normalization and newly recovered old-core edges,
separately from direct new-cell lesion effects. All pre-existing global numerical
parameters, including the common 20-ms model pole, remain unchanged. Applying
that inherited global pole to newly added nodes is an explicit *numerical
assumption*, not a measured cell-specific time constant or physiological finding.
No new electrical conductance, cell-specific pole or fitted synaptic gain is added.
Electrical evidence can establish a missing mechanism without supplying its
conductance; retain unresolved electrical synapses as a documented gap.

## Frozen diagnostic details

The downstream diagnostic uses the existing `malecns-v1.0-yaw-retinotopy-public-v2`
three reversal stimuli at the original 10-ms graph-input clock and the original
1-ms solver. Its analytic local flow is **signed**, unlike the rectified visual
frontend. The expanded batch wrapper permits that signed diagnostic in [-1,1];
all walking comparisons still reuse the unchanged [0,1] Study A arrays. This
historical clamp, its eye map and its signed epoch-difference formula are retained
as a separate diagnostic precisely because they are not a physiological substitute
for image-to-T4/T5 transduction. Whole-fly calibration/validation assignments from
the existing narrowed Figure 3e contract remain unchanged. No new measurement or
neural parameters are calibrated. Report raw endpoint errors separately by split,
role and circuit; no biological acceptance criterion is inferred retrospectively.

Before freezing, test the seven-source-group solver against the original kernel
on artificial random inputs and every expanded graph copy against the Python
reference. After experiments, independently recompute all final grouped currents,
cell means, detection/sign/false-positive counts and sustained thresholds. Retain
all sixteen original visual timing refinements and count every decision change
for all three decoder comparisons. Absence of an invented GJ matrix is a limitation,
not evidence of negligible electrical coupling.

The post-execution reference audit additionally reintegrates two complete small-yaw/
straight source sequences through the Python equations for intact, bIPS-silenced
and dual-new-family-silenced copies (six trajectories). Two intact ±2°/s sources
are also integrated with half the solver step while their delivered inputs remain
unchanged. Save these solver-only outputs and absolute errors separately from the
joint visual/input/solver timing refinements. These are numerical diagnostics,
not additional biological acceptance rules.

This is a bounded family reconstruction, not every neuron in the full brain. In
the same complete raw-weight scan, retain all incident chemical connections between
selected central pathway cells and omitted partners, with annotated peer types,
counts and direction. Report these remaining gaps explicitly, including other
central partners when present; do not infer their functional irrelevance. The
same prospective two-family inclusion rule determines the comparative circuit.
