# Execution wording correction R3

2026-10-29. Before decoder fitting or final-test rendering, source review identified a documentation-only dimensional error in the frozen execution protocol: it describes the inherited frontend as having a 2-degree neighbor displacement and 6-degree pooling support. The actual frozen configuration has `neighbor_steps=1` and `pooling_radius_steps=3` at 1-degree pitch: **1-degree neighbor separation and nominal 3-degree pooling radius**. The half-pitch profile correctly uses 2 and 6 *grid steps*, respectively, at 0.5-degree pitch, preserving those physical distances. The radius is the lattice-radius parameter; the discrete box-average kernel includes both endpoints and is not a continuously calibrated physiological receptive field.

No numerical code, model parameter, spatial configuration, input, criterion, fit or result is changed. Both implementation profiles already implement the intended inherited support distances. The original protocol and before-pilot freezes remain unchanged. This note corrects the explanatory units, not a simulation failure or biological finding. The larger project still has a functional T4/T5 surrogate, not a validated upstream physiological circuit.
