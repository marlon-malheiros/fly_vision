# Final open-loop execution protocol V1

Date: 2026-10-29. Execution of the [fixed milestone plan](FINAL_OPENLOOP_MILESTONE_PLAN_V1.md), with no neural or observation-parameter optimization. This protocol is frozen before new scientific images. Known-room pilot results are implementation/resource checks only.

The machine-readable [execution configuration](../configs/final_openloop_milestone_v1.json) fixes seeds, conditions, workers and replay cases. There are 12 training, 12 calibration/audit and 60 final test rooms, balanced between empty and three-sphere rooms. Seed overlap with every existing top-level scene inventory is prohibited. Invalid geometry causes a stop and a documented versioned correction before response analysis, rather than outcome-driven scene replacement.

The ten model copies, frontend, image/solver clocks, lesions, criterion counts, sign requirements and no-retuning rule are exactly those in the plan. All LPi perturbations use the same LPi-intact decoder for the primary intervention comparison. Every variant also receives an independently trained decoder using the same fixed recipe as a declared secondary information-accessibility comparison. Training consists of one bilateral feature pair at sample 119 (1.19 s) per episode, labeled by prescribed yaw (stationary/straight zero); 192 training rows pooled over speeds. Calibration cannot select coefficients or acceptance rules. HS, H2 and bIPS use the same recipe as secondary readouts. The DNp15 readout is primary. Decoder output units are decoder-equivalent degrees/s, not physiological voltage or a calibrated physical angular-velocity estimate.

Sample 119 uses the 100-ms 1.10–1.19-s current window minus the 0.90–0.99-s window. The 190-ms endpoint is inside the planned 200-ms deadline; the same endpoint determines all primary counts. First correct detected samples through 1.20 s supply secondary latency values; a transient earlier success cannot rescue an incorrect endpoint. Undefined required samples fail. Straight/stationary any-alarm counts cover [1,3) s, one count per room/condition. The fixed cutoff is abs(score)>1, with ties straight. A first-sample NaN in the image comparator is outside all required-ready windows. The unchanged legacy hybrid has no stationary calibration; its walking-only results are explicitly conditional, and it cannot pass the full stationary-inclusive criterion by treating missing speed-zero outputs as correct.

Analyses retain all directions, speeds, curves, and models. Room-cluster percentile bootstrap uses 2,000 resamples with the fixed seed; each resample's room indices are shared across signs, speeds and model copies. The principal lesion effect is lesion-minus-intact change in joint detection and false-alarm fractions, with paired room intervals. Re-estimating a decoder after lesion is secondary, never a replacement for a failed fixed-readout comparison. Biological causality is not inferred from interventions in these equations.

No neural state is reset at yaw onset. All 13,579 source cells retain their original incoming recurrent edges and hidden states. Silencing means zero output/activity and external drive, using the inherited active-mask semantics; it does not clamp hidden state or renormalize weights. bIPS silence and removal of all outputs must agree in non-bIPS observable rates. Sham must be bitwise identical. Outgoing-edge masks, IDs, matrix provenance and baseline parameters are archived before the pilot. All inputs are shared across copies within an episode.

Storage: retain all wide-field observable rates, 100-Hz reference scores, epoch-mean source-group chemical currents, scene/trajectory recipes, software/source hashes, incremental hashes of every retinal frame and source drive, final/checkpoint-state hashes, summaries and receipts. Retain complete movies, source drives, full hidden-state checkpoints and observable currents for one known pilot (-2 deg/s, 16.5 mm/s) and four prospectively named fresh replays. Movies use the existing lossless XOR/deflate codec. No lossy substitute is used. Remaining movies can be regenerated, and exact hash equality is required for replay. The resource pilot must show sufficient disk before fresh images are rendered. Runtime feasibility is measured, not promised.

Numerical subset: the first three rooms in the saved ongoing-walking scene list, crossed with three walking speeds and yaw 0/±2 (27 cases). Each has primary, half-pitch spatial, half image/input-step temporal and half solver-step profiles. Spatial half-pitch retains 2-degree neighbor displacement and 6-degree pooling support under the existing support convention. Temporal output/readout remains 100 Hz. Solver refinement keeps the original one-millisecond forcing ramp rather than shrinking the ramp. Convergence criteria are the plan's 1e-7 solver-state and 0.2 decoder-score tolerances plus no decision flips. Preserve failures. A label-free current/past input monitor is checked independently against batch arithmetic. Check trajectories by finite differences, renderer against NumPy intersections, analytic yaw projection, sign conventions, source identities and state continuity. Independent short-step SciPy/Python RK4 checks and strict-vs-fast activation checks distinguish numerical acceleration from altered equations.

Physiology is bounded to two source families: Suver et al. 2016 and Pokusaeva et al. 2024. No third family or repeated search for unavailable Erginkaya G3 files is needed for this release. Suver has prior qualitative inspection. Its DNHS1 population motion curves report spike rates, while the inherited model is an uncalibrated rate/state system; its HS curves report voltage. Exact starfield seeds/generator and trial-level DNHS1 voltage data have not been identified. This prevents an exact DNp15 voltage benchmark from that source. Pokusaeva supplies HS direction/contrast/frequency voltage source data in a linked 148.9-MB archive; eligible control-cell direction curves use 0.04 cycles/degree gratings, 1-Hz motion, a 2-s baseline and 2-s motion, and per-cell normalization to maximum response. The archive and supplementary geometry must be successfully retrieved and audited before any numerical targets are extracted. If unavailable or geometry/cell-identity matching remains unresolved, record a source-limited status instead of selecting a convenient figure or inventing a display registration. No numeric target has been extracted at this freeze. If eligible, a separate endpoint freeze must precede target extraction and model scoring; otherwise the physiology stage exits with explicit gaps and no physiological-validation claim. [Suver primary source](https://authors.library.caltech.edu/records/mqzzc-va989); [Pokusaeva primary source](https://www.nature.com/articles/s41467-024-53173-w).

Completion requires the entire held-out study, refinement failures, independent metric audit, deterministic replays, figures, technical/professor/plain-language reports and a verified immutable archive. Distinguish package completion, neural capability and physiological evidence. Stop after the held-out verdict; scientific revisions belong to a future version. No closed-loop control or hardware claim.
