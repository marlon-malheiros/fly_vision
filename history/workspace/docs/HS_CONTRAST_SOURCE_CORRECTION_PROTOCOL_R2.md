# HS contrast source-order correction R2: freeze before model scoring

2026-11-02. The [V1 protocol](HS_CONTRAST_VALIDATION_PROTOCOL_V1.md) and its literal spreadsheet extraction remain unchanged. During the planned source audit, before reading any new model response summaries or running the model-scoring stage, the extracted PD curve decreased strongly with its *labeled* contrast. Investigation of primary sources exposed a material inconsistency:

- Source Data 5, sheet 5l labels columns B:F as 10,25,50,75,100%.
- The pinned author `make_group_plots_contrast_levels.m` exports unchanged `mean_contrast(:,1:5)`/`(:,6:10)` at lines 204/205 and labels those axes high-to-low at lines 237/255 and four later plots. It does not reverse the response columns before export.
- Published Fig. 5l shows a rising control PD curve and increasingly negative ND curve. The worksheet's **reversed** column means, with the common source-unit factor 100, approximate the figure's positive and negative voltage levels; the literal ordering has the opposite trend. This check is independent of model predictions. Generic stimulus-code defaults have only three contrast levels and cannot establish the exact five-level recording LUT.

Thus use a separately identified, **source-supported reverse-order interpretation**, B=100,C=75,D=50,E=25,F=10%, and retain the literal header interpretation as the original protocol result and a source discrepancy. This is a correction to an inference about external labels, not an authorized edit of the publisher data or confirmation from raw stimulus logs. Absolute source voltage scaling and actual projector LUT remain unresolved; normalized curves avoid the common scale.

All 120 source numbers were already extracted under V1 before this correction. Do not call R2 biologically blind: both the paper and source responses are inspected, and source ordering motivated this correction. Freeze this correction and its analysis code **before any newly simulated model response is scored or summarized**. No circuit, frontend, decoder, stimulus input, numerical criterion, row inclusion or biological decision margin changes. Reuse the identical simulated contrast bank for both interpretations.

R2 retains V1's eight normalized 10/25/50/75% PD/ND coordinates, PD100 anchor, independent-row and unverified paired-row bootstraps, simultaneous band construction and numerical checks. Under the corrected mapping the previously inspected V1 100%-labeled column is *10%*, so it is not a new independent validation endpoint. No newly extracted contrast is called a held-out animal. No parameter is fitted to these outcomes; the comparison is fixed-model conditional physiological benchmarking.

Independent checks: parse raw XLSX cells and independently reverse their assignment; compare all primary targets, both bootstrap schemes and all model curve/compatibility results; preserve figure and pinned scripts, source/figure/correction hashes, and the before-scoring timestamps. A prespecified source-only figure check samples the blue PD and ND means near x pixels [755,881,1006,1131,1255] and compares the raw column means under both orientations, allowing for figure rasterization. This check supports order, not stimulus reconstruction. Do not digitize a model-dependent best-looking segment or change biological criteria after scoring.

The earlier [HS voltage report](HS_VOLTAGE_BENCHMARK_REPORT_V1.md) compared model full-contrast predictions against the worksheet's 100%-labeled column. Its arithmetic remains reproducible, but identifying that column as actual full contrast is no longer supported. Preserve the sealed report, publish a correction, and do not use its broad scalar interval as a valid full-contrast physiological conclusion. The new report must state both this correction and the corrected contrast-curve outcome, including negative or numerically sensitive findings. Broader biological validity and the successful computational small-turn detector are not changed by source-label bookkeeping.
