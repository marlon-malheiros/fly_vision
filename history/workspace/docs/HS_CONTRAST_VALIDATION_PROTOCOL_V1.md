The two full-contrast values are declared previously inspected controls, not new validation endpoints. No offset, sign, time constant, response saturation, nonlinear measurement transform or gain search.

Primary uncertainty: 10,000 bootstrap draws, seed 2026110203, independently resample 12 row vectors in each direction, retaining each row's five-column covariance. PD/ND row pairing is not assumed. A row-order-paired sensitivity uses identical PD resample indices for ND, explicitly without verified pairing. Normalize each draw by its resampled PD 100% mean. Preserve and count invalid denominators; if more than 1% are nonpositive, mark the ratio uncertainty inadequate rather than hiding draws. The observed anchor must be positive.

For each scheme compute bootstrap standard deviations for the eight primary coordinates, and the 95th percentile of the maximum absolute standardized centered bootstrap deviation across those eight coordinates. The resulting simultaneous mean +/- critical*SD band is a **descriptive recording-row bootstrap band**, not a verified animal-level confidence region, a prediction interval for individuals, or an equivalence margin. A model curve is conditionally compatible only if all eight coordinates fall in the primary simultaneous band; disagreement does not uniquely identify circuit versus stimulus/measurement error. Being inside a broad band is not proof of biological validity. Never replace this rule with a favorable post hoc subset or assert a publication-quality population test from unidentified rows.

## Stimulus and fixed sensitivities

Square-wave grating, spatial frequency 0.04 cycles/degree, temporal frequency 1 Hz (25 degrees/s image displacement), PD increasing body azimuth in the right field, ND reversed; four phases 0,pi/2,pi,3pi/2. Two seconds static, two moving, one static, no onset phase reset. Display at 60 Hz. Baseline [1,2), motion [2,4); initial-window sensitivity baseline [1.5,2), motion [2,2.5). This is a visual assay, not a walking trial.

Three prespecified display profiles: methods85_4bit uses azimuth [-70,70], elevation [-22.5,62.5], with luminance levels round(15*(0.5 +/- contrast/2))/15; figure90_4bit instead uses elevation [-25,65]; methods85_continuous uses the unquantized nominal levels. Outside display is the inherited 8/15 grey. Actual quantized contrast is reported, since nominal 10% cannot be represented exactly with 4 bits. These bracket a missing projector LUT/registration, not recovered calibration. No favorable profile selection. Full-contrast 4-bit primary cases must reproduce earlier input and neural hashes; reuse their retained observations without rerunning them.

120 main image slots (3 displays x5 contrasts x2 directions x4 phases), including 16 reused full-contrast cases. Six stationary controls: for each 4-bit field, zero-contrast moving and stationary 10%/100% patterns. Eighteen numerical variants: methods85_4bit, phase zero, contrasts 10/50/100%, both directions, half image/input time step, half solver step, and half-degree retinal grid. Original image/input steps are 5/10 ms, solver 1 ms; half solver preserves the 1-ms forcing ramp. Spatial sensitivity preserves 1-degree neighbor displacement and 3-degree pooling-center radius by doubling their step counts; the finite averaging-box quadrature changes and is explicitly a spatial-discretization sensitivity. All primary retinal and neural parameters stay unchanged.

Three circuits share each rendered input. Save compact 100-Hz wide-cell rates, source/image/final/checkpoint hashes and run receipts, not movies or full T4/T5 traces. Numerical response tolerance is 0.05*max(abs(primary response),abs(primary full-contrast PD phase-zero reference)) +1e-7, with normalized two-direction response changes <=0.05. These are numerical screening criteria, not biological acceptance margins. Report every failure and distinguish full spatial/temporal convergence from inherited fixed-grid functional comparisons. All stationary and pre-motion rates must be <=1e-12.
