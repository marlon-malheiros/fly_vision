# Perspective-reference repair protocol V1

1 November 2026. Freeze after seeing the negative spherical-chart development results and before rendering perspective inputs. This is an explicit post-failure computational interface repair, not a new biological discovery or untouched validation. Preserve all prior native and spherical outputs.

The native decoder was trained on perspective Sintel images sampled on a flat Cartesian receptor map. A spherical angular chart does not share that image-plane flow geometry. Test a physically consistent perspective reference using the same eye centers, origins, actual 3D scenes, checkpoint, dynamics and decoder. The central image-plane scale remains the inherited pitch 180/31 degrees per receptor; it is not selected by performance. Use native image-plane x=pitch*v and y=-pitch*(u+v/2), converted to dimensionless tangent-plane coordinates by pi/180. A ray is proportional to C+x*Ex+y*Ey, where C is the inherited eye center, Ex is the mirrored native horizontal tangent, and Ey is world up. Average the same 5x5 aperture quadrature, now in that plane. This is a computational camera reference; it does not establish the fly's actual eye optics or MaleCNS specimen registration.

Repeat all 32 already-inspected-world episodes and retain the same causal 100-ms minus 200-ms-earlier feature, 1.19-s endpoint, [1,3) alarm interval and cutoff rules. Keep the canonical two-by-two observation conversion unchanged. Three readers remain binocular mean, geometry-weighted mean and geometry-weighted median. Derive the perspective forward-translation and yaw basis directly by differentiating projection: t=(-Ex_x+x*C_x, -Ey_x+y*C_x); r=(dot(-z_cross_D,Ex)-x*dot(-z_cross_D,C), dot(-z_cross_D,Ey)-y*dot(-z_cross_D,C)). Remove unknown forward depth/speed using (t_y*u-t_x*v)/(t_y*r_x-t_x*r_y), with fixed squared-denominator weights and central extent-10 support. Include an independent finite-difference projection check before interpreting scores. Eye-origin orbit adds a small depth-dependent yaw translation; it is retained in rendering and remains an approximation of this depth-free reader, not silently removed.

No training or new synapse is allowed. Failure means this fixed perspective interface and these readers did not solve the development conditions. It does not exclude other neural decoders. Only an adequate candidate can advance to a new frozen calibration/test protocol; no fresh rooms will be called validation of a failed development candidate. Physiological T4/T5 and MaleCNS reconstruction gaps remain independent.
