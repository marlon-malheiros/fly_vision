# Image-to-neural frontend: short summary for the supervisor

Prepared 13 October 2026. [Complete technical report](PROFESSOR_FUNCTIONAL_FRONTEND_TECHNICAL_REPORT_V1.md).

**We built a working image-to-neural frontend and verified its computation.** It samples physical movies as local brightness, computes motion through fixed spatial wiring and delays, and drives the unchanged MaleCNS circuit. No movie direction labels or target preferred-angle fields enter the numerical detector.

- Every one of the **13,579 source targets** has complete spatial support.
- **Four textures each pass all eight horizontal group criteria**; supplemental speeds pass **16/16 groups** and cardinal gratings **16/16 comparisons**.
- All **ten HS/H2 targets** have the expected measurable global preference in each texture: **40/40**. Ipsilateral unilateral contrast signs also pass **40/40**; STATIC remains stable.
- **28 focused tests** pass. Separate numerical implementations verify all **47 source executions** and **28 network trials**. Failures, recoveries, and a precision-export correction are preserved; no scientific tolerance was relaxed.

**The scope is a functional surrogate.** Eye charts, temporal/spatial constants, and subtype output routing are declared assumptions. Routing specifies which computed channel is delivered to each subtype; its anatomical agreement is not an independent discovery. Vertical slots retain horizontal-texture responses. We have not validated this new model against real T4/T5 recordings or established biological degeneracy.
