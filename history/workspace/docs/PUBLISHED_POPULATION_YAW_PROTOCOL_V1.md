# Published neural-population yaw readouts V1

1 November 2026. Separately frozen follow-up. Spherical-chart development and canonical outcomes are known; perspective outcomes are still being generated when this protocol is written. The perspective geometry is selected to match the published training camera, not selected from a comparison score. No model neuronal parameter is trained.

Use the original FlyVis 1.2.0 checkpoint and all 34 native output populations, with the physically consistent perspective camera and original exact walking poses. Source equations, original decoder and parameters remain unchanged. The primary artificial readout observes actual rectified potentials pooled in four-by-three fixed image-plane bins per eye/type. Empty bins are zero. Its inputs are the causal 100-ms mean level and the same mean minus the level 200 ms earlier: 1,632 features. A secondary linear reader sees the identical level/change statistics of the native decoded two-dimensional field, 96 features. Both are supervised artificial neural readouts; neither represents identified HS/H2/bIPS/DNp15 connectivity. No image-motion estimator, world depth, actual speed, room identifier or onset flag is an inference input.

Collect training inputs from the 12 explicitly listed previously inspected p rooms and six disjoint w calibration rooms. New source activity is generated without fitting it. For every room use one stationary episode and 0/plus-or-minus 2/plus-or-minus 5-degree/s yaw at 5.5/11/16.5 mm/s. Walking begins at .5 s, yaw at 1 s. Stationary/straight episodes last 3 s and contribute every 10-ms callback in [1,3). Nonzero-yaw episodes last 1.3 s and contribute only the 1.19-s endpoint. Inference is causal, so the different saving horizons do not change the endpoint. Keep only declared feature samples and source/image hashes to bound storage; preserve a full observation replay example.

Give -/zero/+ classes equal total weight and each episode equal total weight within class. Regress yaw in degrees/s. Compute feature centering/scaling only from training data, floor 1e-12. Primary: 1,632 -> 32 tanh -> 1 network, fixed seed, float64 full-batch Adam, 600 steps, learning rate .003, weight decay .001. Secondary: weighted ridge .01 on mean loss, intercept unpenalized. No early stopping, hyperparameter search, candidate substitution or fit changes after calibration. Reuse the tested fitting implementation and independently check ridge via augmented least squares and MLP inference via NumPy versus Torch.

Freeze both fits before calibration. For each reader, set one common cutoff to max(1, maximum absolute score across all stationary/straight calibration callbacks). No positive calibration example chooses a cutoff. Evaluate all positives and negatives with the same fixed rules. Qualification requires >=80% detection and correctly signed detection, including each sign, and <=10% episode-level straight and stationary false alarms at every speed and both yaw magnitudes. Report both readers and training/calibration failures. If neither passes calibration, stop this candidate family rather than spend untouched test rooms on a knowingly failing model. This is a predeclared go/no-go decision, not evidence that all neural readouts are impossible.

Only if at least one qualifies, freeze fits, cutoffs, source and the full eligible list before rendering 24 independent seed-disjoint rooms. Test all eligible readers once, preserve their full counts and signs, and use the same gates. Same-family room testing alone does not establish other texture/environment families or arbitrary trajectories. No fresh physiology is supplied by these simulations. A successful behavioral candidate requires a separate frozen space/time/solver stability check before being called a bounded working result. Do not call the larger biological MaleCNS assignment complete from this external readout.

The observer retains full native states transiently but pools them without feeding anything back. Before training inputs, verify that recording full states leaves a complete canonical flow and final state bitwise unchanged. Compare the first neural/population input with direct saved full-state pooling. Preserve all failed runs and a dated progress snapshot on completion. No closed-loop control or speculative electrical connection is added.
