# T5 evidence audit V1

This is a post-analysis audit of completed evidence, authorized after the active
sensitivity study. It is not a new prospective scientific experiment. Preserve
all sealed sources and results; write the independent checker and audit into new
files. Record actual UTC timestamps and every failure/correction in the live
progress report.

The audit will verify ten study index digests and every indexed file; separately
verify the original seven-condition assignment's bundle. Recompute all 84 sets'
156 readouts from saved voltage, validate clocks/identities and stimulus pairs
from metadata, and independently recalculate every stored candidate/reference
decision using the saved configuration. Check the voltage/conductance algebra
and reconstruct both finite-difference matrices. Reuse the preserved previous
matrix-exponential review as evidence; do not represent it as rerun today.

Add descriptive comparisons of singular values, weakest vectors and subspaces
between the two saved finite-difference steps. They have no new acceptance
threshold and cannot establish exact rank/identifiability or a rigorous numerical
uncertainty bound. No new model responses, candidates, fitting or gate changes.

Investigate the hard-coded response/waveform/pair thresholds in the sealed V1
scorer with a counterfactual synthetic fixture. If confirmed, provide an
independent configuration-driven checker rather than edit the sealed source.
Distinguish a latent reuse defect from an error affecting executed results.

Test corruption detection, missing/duplicate trial identity and directions,
metadata-based pairing, missing windows and malformed arrays, threshold changes,
and altered saved verdicts. Run relevant existing sensitivity tests as regression
coverage. Stop after these checks and the evidence audit pass unless a new
failure warrants further investigation.

Deliver a detailed audit, a one-page supervisor brief and alternative execution
plans with explicit scope, prerequisites, stop criteria, deliverables and claim
limits. Map all 14 original professor instructions to evidence. Distinguish
completion of a model diagnostic, a narrow computational compensation result,
and biological degeneracy. Confirm public author-source availability where
needed; do not download a new ensemble, run a search, publish or message anyone.

Save commands, logs and test results; snapshot the live progress report and seal
the new audit package. Existing numerical evidence remains unchanged.
