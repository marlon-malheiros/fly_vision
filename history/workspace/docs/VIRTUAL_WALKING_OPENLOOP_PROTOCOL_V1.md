# Virtual walking open-loop study V1 — audit and execution plan

Prepared 2026-10-15 (America/Belem), before new walking neural responses.

Audit starting point: [professor handoff](PROFESSOR_FUNCTIONAL_FRONTEND_TECHNICAL_REPORT_V1.md), [functional study](FIXED_NEIGHBOR_MOTION_REPORT_V1.md), and its sealed artifact index. Existing source is a functional fixed-neighbor surrogate, not validated T4/T5 physiology. Frozen graph: 13,593 cells, including all 13,579 T4/T5 inputs, 8 HS, 2 H2, 2 PS321/bIPS and 2 DNp15; 203,861 chemical edges and no gap edges. Preserve original code, graph, routing, parameters and sealed evidence; add new modules only. Read the legacy repository without modifying it. Existing temporary source interpreter is absent; use the available frozen downstream Python environment and record versions.

Execution plan:

1. Implement deterministic textured box/sphere ray casting, separate eye origins 0.3 mm apart, the inherited angular eye charts and the unchanged panorama-to-retina sampler. Camera/body orientation is fixed together. Prescribed planar trajectories integrate constant body-forward velocity and yaw exactly. This is a visual rigid-body walking surrogate without leg dynamics, gait or motor feedback.
2. Freeze code, tests, scene seeds, physical speeds and analysis before observing new neural outputs. Three scenes: development corridor, held-out wider room with new texture, held-out asymmetric clutter with new texture/depths. No parameter selection or scene exclusion based on outputs.
3. Execute 12 conditions per scene: stationary; forward 5.5/11/16.5 mm/s; yaw ±55.5 deg/s; each forward speed combined with each yaw sign. Duration 2 s, movement 0.5–1.5 s, frontend 5 ms, network drive 10 ms and RK4 integration 1 ms as in the predecessor. Response window 0.7–1.4 s. Separate refinement: development static, fast forward, pure positive yaw and fast positive compound at frontend 2.5 ms, network drive 5 ms, solver 0.5 ms. Also refine solver alone for the same compound input.
4. Record images, retinal inputs, routed drives, pooled channels, all 14 downstream full-precision trajectories and full-network sampled states. No intended velocity/condition enters the motion module or direct input to downstream cells. Independently check scalar ray intersections, analytic flow against fixed-landmark reprojection, flow superposition, depth dependence, static, mirror and replay controls. Reimplement the source with a different temporal filter and pooling algorithm; compare the streamed graph solver against the original legacy solver. These are numerical checks, not independent laboratory validation.
5. Report each cell and class, stationary-subtracted means, R−L asymmetry and normalized asymmetry (difference divided by sum of absolute side means plus 1e−12). Describe yaw-versus-forward selectivity using pure-yaw magnitude averaged over directions and translation magnitude at each speed. Retain signed rates, including inhibition. For discrimination, freeze a nearest-centroid readout using the development scene only: classify no-yaw/positive-yaw/negative-yaw from class-specific bilateral responses. Standardization and centroids use development conditions only, then apply unchanged to both held-out scenes. This readout is an analysis instrument, not a modified neural circuit. Report balanced accuracy, confusion matrices and every error; no biological p-values or population confidence from deterministic scenes.
6. Interpret original and held-out results without response-based tuning. Compare qualitative patterns with Erginkaya et al. (2025), including translational suppression and rotational selectivity of DNp15 relative to HS, and speed-dependent bIPS effects. The paper's display stimuli/units differ from physical 3D depth-aware scenes, so this is not a quantitative recording reproduction. No silencing experiment or causal disinhibition claim in this frozen study. No closed-loop controller.
7. Preserve failures and corrections. Create report, figures, undergraduate explanation, exact reproduction commands, dependency pins, progress snapshot and immutable artifact index. Live AGENTS.md and progress report stay outside artifact indexes.

Prospective engineering checks: static source/rates ≤1e−10; independent source error ≤1e−7; original-solver error ≤1e−10 at recorded downstream cells; scalar depth error ≤1e−8 mm; analytic angular-velocity error ≤1e−4 rad/s; mirror retinal error ≤1e−7; refinement means compared using absolute error and relative denominator floor 0.001, flag >10% changes. Refinement failures limit interpretation and are not permission to retune. No required accuracy or literature agreement gate: the neural result is exploratory under frozen methods. Timestep checks cover the named subset only; no universal convergence claim.
