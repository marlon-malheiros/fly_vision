Reconstruct alarm counts, first-alarm times, durations and signed score contributions from each DNp15 side. Decompose features into common and differential components using the original coefficients. Check the same times in HS, H2 and bIPS and in the saved independent image reference; this is localization/correlation, not proof of biological causality. Compare the ten fixed model copies on identical inputs. No new classifier or threshold sweep.

Regenerate source drives for those six rooms at all three speeds; verify original image/source hashes. Retain source-channel and eye statistics, and run the intact LPi graph with full currents for those episodes to reproduce saved rates and trace upstream chemical contributions. Use direct weighted T4/T5 drive, saved neuron activity and exact algebraic readout decomposition. Source/neuron traces have arbitrary model units; their numeric scales are not interchangeable.

Only if the observed pipeline supports a concrete hypothesis, add one bounded diagnostic with its definitions recorded before execution. Do not search gains, lesions or operating thresholds. Any counterfactual is a model intervention, not a biological claim. Report unresolved localization explicitly. Do not call a large image-reference score proof of true yaw, since true yaw is zero in these controls.
