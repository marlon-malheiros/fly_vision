## Frozen design

Twelve new independently seeded scenes: three training, three calibration and six held-out testing. Scene geometry and textures are generated without neural outputs, then written explicitly to config. All scenes contain a floor and enclosing walls; alternating scene identities contain asymmetric opaque spheres with collision-free prescribed paths. Seeds 91601–91612. Each scene: all three forward speeds (5.5,11,16.5 mm/s) crossed with yaw 0,±2,±5,±10,±20,±40°/s (33 conditions), plus a stationary observer. Thus 408 primary visual inputs. Duration 2 s, movement 0.5–1.5 s, scoring 0.7–1.4 s. Primary frontend 5 ms, graph input 10 ms and RK4 1 ms. Source/neural values stay in original normalized units; no invented neural noise.

Twelve independent graph copies per input: intact; sham; bilateral bIPS output silencing; left bIPS silencing; right bIPS silencing; removal of all bIPS outgoing chemical edges; removal only of bIPS→DNp15; only bIPS→HS; only bIPS→H2; only bIPS→bIPS; bilateral HS silencing; bilateral H2 silencing. Silencing sets emitted rate to zero using an active-mask copy; its latent state may still integrate incoming current. Edge removal sets only the specified existing matrix entries to zero, without renormalization or any new edge. Original matrices stay unchanged. Record pre/post IDs, removed weights and edge counts. Sham must replay intact exactly. Bilateral bIPS silencing and all-outgoing removal must give identical responses outside bIPS, providing an equivalence control. All twelve copies receive the very same saved drive array, not independently rendered lesion inputs.

## Decoder, metrics and threshold rule

For each speed and cell class, average cells within each side and use [L,R] signed response-window means. Fit a signed-yaw ridge regression (feature standardization on training only; ridge coefficient 0.001, unpenalized intercept) on the three training scenes. This is an analysis readout, not neural parameter fitting. Detection threshold on the absolute predicted yaw is the maximum straight-walking score in the three calibration scenes; equality means no rotation. Predict direction from signed predicted yaw. No held-out data enter fitting or calibration. Primary lesion comparison applies the intact decoder unchanged; secondary comparison fits each lesion's decoder using only that lesion's training/calibration scenes. Decoder is conditional on the specified forward speed; speed is not inferred from neural activity.

For each nonzero yaw magnitude and speed, report detection rate, unconditional yaw-sign accuracy among actual rotating cases, three-class accuracy including straight walking, and straight-walking false-positive rate. Retain every prediction. Primary detection threshold is the smallest tested magnitude at which detection and sign accuracy are each ≥80% and held-out false-positive rate ≤10%, sustained at all larger tested magnitudes. If detection/sign criteria never pass, report >40°/s under this rule; if the false-positive criterion fails, mark the threshold unresolved rather than interpreting it as a physical lower bound. If the smallest passes, report ≤2°/s (never extrapolate below the tested grid). Also report the first isolated crossing and full nonmonotonic curves. No threshold retuning after outcomes. Six held-out scenes are a small finite sample: report counts, scene-cluster resampling and Wilson intervals descriptively; do not call these fly psychophysics or biological uncertainty. No arbitrary sensor/neural noise is added to obtain a desired threshold.

Mechanistic readouts: paired intact/lesion DNp15 changes, class bilateral asymmetry, signed-yaw slopes and input-current contributions grouped by source role. Currents are reconstructed from existing weights and recorded full-network rates during the solve. Model interventions can demonstrate effects within these equations only; they cannot establish biological causality or compensate for missing gap edges, uLPTCrns or H2rns.
