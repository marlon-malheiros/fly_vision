# Causal sensor-time integration correction R2

16 November 2026. This amendment follows inspection of V1 outcomes; it is not part of the original pre-outcome protocol.

V1 reduced disturbance RMS on all 36 intact test cases, but its half-step guard failed: the largest relative RMS change was 0.05220677, exceeding the unchanged 0.05 limit. V1 remains FAIL in results/v1, with the original source tree copied to results/v1/source and the original calibration retained separately.

The V1 correlation detector used a low-pass state from before the current frame and updated the state afterward. Its effective delay therefore included a frame-dependent contribution. R2 integrates the declared first-order continuous temporal filter to the current observation using the exact solution for a linear interpolation between the previous and current observations. It is causal, uses only observed image history, and has a new analytical ramp-response test. Circuit topology, weights, neuron dynamics, motor plant, target loop gain and acceptance thresholds are unchanged.

After V1 and before any R2 outcome, the user requested a traditional random-dot/square stimulus instead of the initial sinusoidal wall textures. R2 therefore also changes the stimulus to a world-fixed random-square pattern on a virtual cylindrical display: 5-degree square width at the display center, nominal 15% area coverage, equal numbers of black/white squares on gray background, 360-degree azimuth and 60-degree elevation, 256x48 camera samples. The display radius is 0.9-1.4 m for the virtual robot; this is not a claim about a biological arena's physical scale. Texture antialiasing uses 0.5-degree texture samples and a declared Gaussian prefilter of SD 0.75 degrees. Squares remain world fixed, so rendered retinal motion is caused by the robot's translation and rotation. Two-dimensional ON/OFF detector responses are pooled within each side.

R2 uses calibration seeds 1201-1204 and new test scenes 9201-9206. V1 test scenes are development evidence for this correction and are not relabeled fresh. The 270-episode comparison and six selected half-step checks are retained with the original metrics and 5% numerical limit. Numerical qualification is conditional on these selected cases; no biological validation is implied. The stimulus settings are engineering choices inspired by laboratory random-pattern displays, not an exact reconstruction of any publication.

Biological scope remains limited: the selected central circuit preserves only about 10-13% of total incoming synapses for PS321/bIPS-associated cells and 14-17% for DNp15. A small bIPS ablation effect cannot establish a biological absence of effect. T4/T5 recurrence, 7,373 recorded central-to-source feedback pairs and many central partners are outside the clamped-source prototype.
